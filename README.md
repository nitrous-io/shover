Shover
======

### Authentication

Use basic auth:

Username: `SHOVER_USERNAME`
Password: `SHOVER_PASSWORD`

### POST /p - publish

Params:

`u` - user id
`e` - event name
`d` - data in json

### POST /b - broadcast

Params:

`e` - event name
`d` - data in json
